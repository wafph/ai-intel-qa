# v12-2-9 前端最小增量说明

## 修改范围

1. 四个功能主体高度保持当前版本，不回退主体页面高度。
2. 左侧 `AI+ 规章制度智能体` logo 高度调整为 56px，与顶部功能栏对齐。
3. 左侧搜索框、新建对话按钮上移并略微压缩高度。
4. 四个功能底部输入框整体向上移动；打开引用/原文定位面板时，输入框按左侧内容区对齐，避免与右侧面板割裂。
5. 智能检索在刷新/切换后，即使历史里已有 sources，也会读取 task detail；当 detail 里的来源块更多时，用 chunk 优先的前端合并策略补全并保存，避免刷新后只剩少量块。

- 四个功能主体高度与主要消息渲染逻辑不变。
- 问答、起草、审核不会因为已有 sources 而额外读取 task detail；仅保留原有恢复策略。
- PDF 上传、PDF detect、原文定位、错误兜底逻辑不做额外扩展。
