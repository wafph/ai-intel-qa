# v12-2-17 前端最小增量说明

本版基于 v12-2-16，仅做以下最小变更：

1. 实时流式首段过滤从“首个双换行前内容无条件丢弃”改为按 `<think>...</think>` 判断，只展示 `</think>` 后的正式内容；没有 think 标签时正常展示，避免误删正文标题。
2. 辅助起草导出改为 `handleExport(item)`，只导出当前回答。
3. 合规审核导出改为 `handleExport(item)`，只导出当前回答。
4. 非标准 PDF 前置检测弹窗文案固定为指定文案，不再直接拼接后端 reason。
5. 合规审核打开原文定位时自动折叠左侧历史栏；用户手动展开/折叠逻辑不变。

本版不处理“复制时仍带 think 标签”的问题，不改后端接口与业务请求链路。
