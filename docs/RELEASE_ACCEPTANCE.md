## 兼容与运行条件

生产使用包内 .env.production，业务同源转发到配套后端。后端平台切换只修改 AGENT_PROVIDER 并重启，前端无需重新构建。问答重传依赖后端 AGENT_UPLOAD_STORAGE_ROOT 中原件/元数据保留。

旧外部附件没有 upload_ref 时不能仅凭旧 URL 重建原件，需重选文件。问答 PDF 缓存实际上传的解析 TXT，不重新解析 PDF。审核不使用问答刷新接口，沿用原审核到期重传策略；跨平台重用旧审核 URL 的可达性需要现场确认，重新选择文件可确保上传到当前平台。
