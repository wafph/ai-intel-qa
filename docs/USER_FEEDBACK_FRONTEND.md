# 用户问题反馈前端说明

## 1. 功能边界

智能体前端只负责提交用户问题，不展示用户的反馈历史、处理状态和处理结果。反馈记录、附件预览、处理更新和导出仍由独立反馈管理端负责。

智能问答页面原有“点踩反馈”继续调用 `/v1/chat/status`，用于评价具体回答；用户菜单中的“问题反馈”调用 `/v1/feedback`，用于提交系统使用过程中发现的问题。两套功能相互独立。

## 2. 页面入口

点击左侧底部用户信息区域打开用户菜单，操作顺序为：

1. 问题反馈；
2. 我的收藏；
3. 退出登录。

问题反馈弹窗默认选中当前功能页，并允许切换到智能问答、智能检索、辅助起草、合规审核或其它。

## 3. 提交字段

请求使用 `POST /v1/feedback` 和 `multipart/form-data`。所属模块、问题描述必填；截图、联系电话和邮箱不显示“选填”文字，也不显示必填星号。

截图支持 JPG、PNG、WebP，最多 5 张，单张不超过 10MB，总大小不超过 30MB。前端自动携带当前认证 Token，并补充当前会话、页面路由和功能页上下文。

## 4. 生产代理

如果生产 Nginx 没有将全部 `/v1/` 请求统一转发到后台，需要增加精确代理：

```nginx
location = /v1/feedback {
    proxy_pass http://后台服务器IP:8000;
    proxy_http_version 1.1;
    proxy_connect_timeout 60s;
    proxy_read_timeout 120s;
    proxy_send_timeout 120s;
    client_max_body_size 32m;
}
```

开发环境继续使用既有 `/api` 代理，无需增加新的 Vite 代理规则。
