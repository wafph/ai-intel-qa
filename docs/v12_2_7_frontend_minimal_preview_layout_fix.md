# v12-2-7 前端最小增量修复说明

本版本基于 v12-2-6 做最小改动，重点避免新分栏预览逻辑影响旧功能。

## 改动范围

1. 智能问答 / 智能检索 / 辅助起草的来源标题点击预览行为回退旧逻辑：
   - PDF 仍使用原来的 PDF 弹框预览。
   - 非 PDF 恢复 openDocumentUrl 打开/下载逻辑。
   - 移除 v12-2-6 新增的通用 with-document-preview 全局分栏覆盖样式。

2. 右侧来源/推荐范文面板打开后，保持左侧操作按钮可见：
   - 打开“查看来源”或“显示推荐范文”后，当前消息操作区保持在可视区域内。

3. 合规审核原文定位布局微调：
   - 原文定位面板改为稳定占满右侧可用高度，减少打开后整体下移。
   - PDF 分页工具条、提示区和页面渲染间距缩小。
   - PDF 页面左侧不再被居中布局裁切。
   - 点击左侧原文片段后，右侧尽量滚动到高亮片段位置。

4. 顶部导航和输入区微调：
   - 顶部菜单高度从 70px 调整为 56px。
   - 输入框高度和底部间距略微收缩，释放更多会话空间。
   - 来源面板打开时输入框继续跟随左侧内容区域横向移动。

5. PDF 前置检测交互修复：
   - 非标准 PDF 检测完成后，弹窗期间不再继续显示“正在检测 PDF 是否支持原文定位...”。

6. 合规审核上传文件卡片新增删除入口：
   - 上传成功后，文件卡片右上角显示 “×”。
   - 点击后清空当前上传文件、解析文本和审核参数，可重新上传。

## 未变更内容

- 不改后端接口。
- 不改 AgentArts 调用逻辑。
- 不改问答/检索/起草/审核的请求参数结构。
- 不改合规审核 PDF detect / prepare / bind-review-file 主流程。
